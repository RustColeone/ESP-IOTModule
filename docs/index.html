Connection requirements and troubleshooting

Your browser and ESP device must be on the same LAN. When asked, allow this site to find and connect to devices on your local network.

Current Chrome or Edge is recommended. If a .local address does not resolve, enter the device IP shown in its Serial Monitor. Reflash the updated firmware first so the read-only dashboard endpoints include the required browser headers.

Device addresses and aliases are stored only in this browser. They are not uploaded to GitHub or another service.
